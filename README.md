# 回声分析台(鱼探仪岸上分析工具)

把鱼探仪导出的双频原始回波文件(`.fvoy`)拿回岸上分析:自动找海底、
拎出海底以上 0.5 m 水层、38/200 kHz 双频对齐识别鱼群与浮游层、
按航次和网次存档,并叠在航迹图上看哪片海常有鱼。

## 快速开始

```bash
npm install        # 仅需 typescript(编译网页端)
npm run gen        # 生成 3 个合成航次 → data/(约 65 MB,真实声学衰减)
npm run validate   # 用真值校验海底检测与鱼群识别精度
npm start          # 编译网页端并启动 → http://localhost:8080
```

## 数据格式(.fvoy)

小端二进制:`FVOY` magic + 版本 + JSON 头(航次、船名、网次、频率、
声速、吸收系数、系统常数)+ 数据体(每 ping 经纬度/航速 Float32,
每通道接收级 Int16,dB×100,ping 主序)。存的是**未做 TVG 的原始接收级**,
岸上分析时按 `Sv = RL − K + 20log₁₀R + 2αR` 还原,α 用
Francois–Garrison 模型(38 kHz ≈ 10 dB/km,200 kHz ≈ 60 dB/km)。

## 合成数据的声学真实性(`src/gen/generate.ts`)

- 球面扩展 + 频率相关吸收(200 kHz 衰减远快于 38 kHz,远距离噪声底随 TVG 上升);
- 船体升沉(0.45 m/7.5 s 主成分 + 短周期分量)→ 海底线锯齿;
- 海底回波主瓣(脉宽决定厚度)+ 指数尾 + 量程内的多次回波;
- 鱼群:椭圆聚合,38 kHz 强、200 kHz 弱(ΔSv ∈ [−9, +1]),约一半贴底(距底 2.8–5.8 m);
- 浮游层:昼夜不同深度(夜间上浮),高频强(ΔSv ∈ [+10, +14]);
- 接收机噪声 + 指数分布散斑。

## 代码结构

```
src/shared/   声学换算 / 文件格式 / 海底检测 / 鱼群识别(生成器与网页端共用)
src/gen/      generate.ts 合成航次;validate.ts 精度校验
src/server/   静态服务器(无依赖)
web/          岸上查看器(画布渲染,无框架)
data/         生成的航次(不进 git)
```

接真实鱼探仪时,只需写一个转换器把厂商格式转成 `.fvoy`
(`src/shared/format.ts` 里有 `encodeVoyage`),分析端不用动。
